# TEI schema

`tei_all-4.12.0.rng` is the unmodified official TEI P5 4.12.0 full Relax NG schema, retrieved 8 September 2026 from:

https://www.tei-c.org/Vault/P5/4.12.0/xml/tei/custom/schema/relaxng/tei_all.rng

Run `npm run validate:tei` from the project root. The validator extracts the 3.7 TEI element from legacy witness wrappers before validation. This schema is not a custom ODD and does not validate source-reading accuracy.
