How to Use This Site

This site provides an interactive workspace for exploring Ovid's Amores. The home page contains three customizable panels that can display texts, manuscript images, or scholarly commentary side by side.

The Three-Panel Layout

Each of the three panels can be switched between four modes: Transcription, Single Manuscript Viewer, Line-by-line Viewer, and Companion.

  • Customizing Your View: On wider screens, resize panels by dragging the vertical borders. Reorder panels with the "☰" handle, or use the "×" control to collapse a panel. On narrower screens, the panels stack vertically so each workspace remains readable.

Exploring the Text
  1. Select a Poem: In the Transcription panel, use the "Select a poem..." dropdown menu to choose which of the Amores you wish to examine.
  2. Choose a Witness: Below the poem selector, the "Witness" dropdown allows you to load the transcription from a specific manuscript source (e.g., P, Y, S, or LL).
  3. Unavailable Transcriptions: If the selected witness has not yet been transcribed, the panel offers the Latin Library (LL) text and any other transcription available for that poem.

Viewing the Manuscripts
  • Single Manuscript Viewer: Select a poem in the viewer panel, then choose P, Y, S, or O to open that witness at the mapped page. O is the Teubner 1888 printed edition. The viewer includes zoom and page-navigation controls.
  • Line-by-line Viewer: Select a poem and use the witness checkboxes to choose any combination of P, Y, S, and O. P, Y, and S are checked by default. Clicking a line in a transcription panel moves each selected witness with an annotation to that line.
  • The line-by-line viewer follows the poem selected in the transcription automatically, while other panel selectors remain independent.

Using Line Annotations
  1. Set one panel to Transcription and another to Line-by-line Viewer.
  2. Choose a poem and witness in the transcription, then click any numbered line. Every selected witness with an annotation for that line moves to the corresponding passage and highlights the active line while retaining nearby context.
  3. Use the Witnesses checkboxes to compare any combination, include printed witness O, or enlarge a single selected witness.
  4. For annotation work, open Tools, choose the target manuscript, select a transcription line, and click Start annotation. Drag a box over the matching manuscript line, then export the JSON when finished.

Annotation edits remain in the current browser until exported; they do not change the published dataset automatically.

Accessing the Commentary
  • The Companion panel provides contextual information. Check the boxes for "Commentary," "Manuscript Commentary," or "Vocabulary" to display the desired notes for the selected poem.

Interactive Linking

The Transcription, Line-by-line Viewer, and Companion panels provide linked reading tools:

  • Hovering: Hover your mouse over a line in the transcription to highlight the corresponding notes in the companion panel, and vice-versa.
  • Clicking: Click a transcription line to move a line-by-line manuscript viewer to its annotated location and scroll the companion panel to relevant notes. Clicking a companion note scrolls the transcription to the corresponding line.

Dark Mode

For a different viewing experience, you can toggle dark mode by clicking the theme toggle icon in the header navigation.

Quick tour

A few things to know before you start.

  1. Pick a poem from the “Select a poem…” dropdown in any panel.
  2. Switch panel type (Transcription / Single Manuscript Viewer / Line-by-line Viewer / Companion) from the panel header.
  3. Inspect one witness in the Single Manuscript Viewer, or click a transcription line to compare witnesses in the Line-by-line Viewer.
  4. Arrange the workspace: drag the ☰ handle to reorder, use × to collapse, and drag gutters to resize.
  5. Toggle theme with the sun/moon icon in the header.
